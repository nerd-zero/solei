Supercharge your AI agents with Solei as a Model Context Protocol (MCP) server.

## What is MCP?

MCP is a protocol for integrating tools with AI agents. It can greatly enhance the capabilities of your AI agents by providing them with real-time data and context.

Solei offers a remote MCP server that you can connect to from most AI clients.

## How does it work?

You need a MCP-capable agent environment to use Solei over MCP. A few of them are Claude Desktop and Cursor.

## Connecting to Solei MCP

Solei provides two MCP servers:

- **Production**: `https://mcp.solei.to/mcp/solei-mcp` - Connect to your live Solei organization
- **Sandbox**: `https://mcp.solei.to/mcp/solei-sandbox` - Connect to the Solei sandbox environment for testing

When you can specify a MCP URL, use one of the URLs above depending on your environment.

If you have to specify a command, use:

```json
{
  "mcpServers": {
    "Solei": {
      "command": "npx",
      "args": ["mcp-remote", "https://mcp.solei.to/mcp/solei-mcp"]
    }
  }
}
```

For sandbox:

```json
{
  "mcpServers": {
    "Solei Sandbox": {
      "command": "npx",
      "args": ["mcp-remote", "https://mcp.solei.to/mcp/solei-sandbox"]
    }
  }
}
```

### Codex

Add the following to your `~/.codex/config.toml`:

```toml
[features]
rmcp_client = true

[mcp_servers.solei]
type = "http"
url = "https://mcp.solei.to/mcp/solei-mcp"
```

Then run:

```sh
codex mcp login solei
```

For sandbox:

```toml
[features]
rmcp_client = true

[mcp_servers.solei_sandbox]
type = "http"
url = "https://mcp.solei.to/mcp/solei-sandbox"
```

Then run:

```sh
codex mcp login solei_sandbox
```

### Claude Code

Run the following command:

```
claude mcp add --transport http "Solei" "https://mcp.solei.to/mcp/solei-mcp"
```

For sandbox:

```
claude mcp add --transport http "Solei-Sandbox" "https://mcp.solei.to/mcp/solei-sandbox"
```

### ChatGPT

MCP is only available for paid users in beta on ChatGPT web, by enabling Developer Mode.

Once Developer Mode is enabled, go to _Settings_ → _Connectors_ and add the MCP server using `https://mcp.solei.to/mcp/solei-mcp`.

For sandbox, use `https://mcp.solei.to/mcp/solei-sandbox` instead.

### Claude Desktop

Go to _Settings_ → _Connectors_ and click _Add custom connector_.

Name it "Solei" and add `https://mcp.solei.to/mcp/solei-mcp` as the server URL.

For sandbox, use `https://mcp.solei.to/mcp/solei-sandbox` as the server URL instead.

Save, and click _Connect_ to connect to your Solei organization.
